# 🚀 Deploy RDN Web App

## Deploy Automatico su Vercel (1 click)

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https://github.com/ethicsel1/rdn/tree/claude/create-rdn-web-app-01HwcHTarQHrmZHGeTMS632T&project-name=rdn-web-app&root-directory=client)

### Istruzioni:

1. **Click sul button sopra** ↑
2. Autorizza Vercel con GitHub (se non l'hai già fatto)
3. Click "Deploy"
4. Aspetta 2 minuti
5. Ricevi il link dell'app live!
