# RDN Standalone Web App

Web app standalone per "RDN - Rinascita Definitiva dai Narcisisti", ecosistema digitale di crescita personale ed empowerment.

## Quick Start

Questo progetto è pronto per essere sviluppato partendo da zero con architettura moderna.

### Per iniziare lo sviluppo:

1. **Leggi la documentazione completa**: `STRUTTURA_PROGETTO.md`
2. **Copia il prompt per nuova chat**: `PROMPT_NUOVA_CHAT.md`
3. **Inizia una nuova sessione** con Claude Code incollando il prompt

## Caratteristiche Principali

- ✅ 3 Schermate interconnesse (Benvenuto, Orientamento, Strumenti)
- ✅ 8 Strumenti di rinascita (4 L1 + 4 L2)
- ✅ Sistema viralità con 30 guide progressive
- ✅ Rituali quotidiani per retention lifetime
- ✅ Abbonamenti Stripe (L1 €9,90/sett, L2 €19,90/sett)
- ✅ Trial 7 giorni €1
- ✅ Sistema emergenza con sicurezza integrata

## Stack Tecnologico

**Frontend**: React 18, Vite, TailwindCSS, React Router, Framer Motion
**Backend**: Node.js, Express, PostgreSQL, Prisma, JWT
**Payments**: Stripe
**AI**: OpenAI GPT-4
